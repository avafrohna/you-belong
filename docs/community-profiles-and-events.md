## Implementation handoff

The companion `community-content-2026-09-25.json` contains all profiles, category IDs, source links, review notes and event candidates. It is intentionally outside the runtime data so incomplete events cannot silently appear as published. Each dated candidate must be normalized into the existing event schema before import: known start/end, explicit Pacific offset, verified venue, original source, review date and correct host. Missing end times remain missing; never convert a timed event into an all-day event to satisfy the schema.

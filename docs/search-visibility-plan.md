# Search visibility plan — September 30, 2026

These are owner-supplied search topics, not claims that the site currently ranks
for them. This is a content plan; the proposed guides have not been implemented.

## Existing foundation

The build already prerenders organization and category pages, emits individual
titles/descriptions and canonical URLs, and generates robots.txt and a sitemap.
Adding a reviewed organization automatically adds its profile to that system.
Search Console indexing and rankings require a separate live check; this review
does not establish current search positions or query traffic.

Start with the newcomer, volunteer, and refugee/immigrant guides. Publish only
substantial, helpful content with real links, source review dates, clear headings,
and natural language. Keep the homepage's mission and design intact. Link guides
from relevant existing pages and include their canonical URLs in the sitemap.
Do not create eleven near-identical keyword pages or repeat a keyword list in
hidden text, metadata, or the footer.

## Google and measurement

- There is no Search Console control that assigns organic rankings to keywords.
- Google ignores the meta-keywords tag. Descriptive page titles, useful visible
  content, and internal links are appropriate improvements; descriptions can
  influence snippets but are not a guarantee that Google will show that text.
- After publication, inspect the new URLs and the sitemap in Search Console.
  Request indexing where appropriate. Indexing does not guarantee ranking.
- Use Search Console Performance to compare query impressions, clicks, and
  landing pages over time. Do not promise a position or date for results.
- Encourage relevant organizations to link to the guide when it is useful to
  their audiences. Do not purchase links or manufacture endorsements.

Primary reference: [Google Search SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide).
